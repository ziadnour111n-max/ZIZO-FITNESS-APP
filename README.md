# ZIZO FITNESS — Update 2.0

## الملفات
- `index.html`: واجهة التطبيق ومزايا النسخة التجريبية المحلية.
- `.github/workflows/build-apk.yml`: ملف بناء APK الحالي؛ احتفظ به ولا تحذفه.

## التحديث الحالي
- واجهة عربية RTL بهوية سوداء وحمراء.
- دخول تجريبي محلي.
- تمارين منزلية بدون أجهزة جيم مع شرح نصي ورسم متحرك توضيحي عام.
- مؤقت تمرين.
- تسجيل أيام التمرين أسبوعيًا وشهريًا.
- حفظ الوزن والمياه والوجبات والسعرات والبروتين محليًا.
- نقاط XP وإنجازات أولية.
- وضع ليلي ونهاري.

## حدود مهمة
هذه نسخة واجهة وتجربة محلية. تسجيل الدخول ليس مصادقة آمنة ولا يربط Google/Facebook. لا يوجد قياس فعلي للخطوات أو نبض القلب أو السعرات من مستشعرات الهاتف. لا تعمل تنبيهات مضمونة بعد إغلاق التطبيق. البيانات محفوظة على الجهاز/المتصفح فقط، وقد تضيع عند مسح بيانات التطبيق أو تغيير الجهاز. يلزم ربط خدمات ومكونات Android أصلية لإضافة هذه الوظائف بصورة حقيقية.

## البناء
يستخدم المشروع ملف GitHub Actions الموجود في `.github/workflows/build-apk.yml` لبناء APK. لا تحذف هذا الملف.
